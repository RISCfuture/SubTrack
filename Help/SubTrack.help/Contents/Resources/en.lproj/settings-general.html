Set the default destination for new queues

Choose SubTrack ▸ Settings (⌘,), click General, and click Change Destination….

New queues start with this destination. It doesn’t touch queues that already exist — each of those keeps whatever it was given — so changing it is safe at any time.

Leave it unset and new queues save next to each source.

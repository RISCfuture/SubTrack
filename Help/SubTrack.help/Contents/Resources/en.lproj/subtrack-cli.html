Install the subtrack command-line tool

SubTrack ships a command-line twin. subtrack runs the same engine the app does, takes one file in and writes one file out, and reads its keep rules from flags rather than from the inspector. It’s for the work a window is the wrong shape for: slimming over SSH, wiring slimming into a script, or looping over a whole library overnight.

It comes with the downloadable version only. The App Store version’s CLI pane says so and offers nothing to click — see Choose between the two versions of SubTrack.

Install the subtrack tool covers putting it on your PATH, including the case where the folder you picked needs administrator access.

Run it

A run is subtrack [options] <input> <output> — one source file, one destination file.

The tool does not carry FFmpeg with it. This trips up nearly everyone. The app’s bundled FFmpeg stays inside the app bundle; what you installed is only the subtrack executable. It looks for ffmpeg and ffprobe on your PATH and stops with an error if either is missing. Install FFmpeg yourself — Homebrew’s is fine — or name the binaries with --ffmpeg <path> and --ffprobe <path>.

The rest of the options are the inspector’s rules, one flag apiece:

  • -l, --language <lang> — a language to keep, as a three-letter code. Repeatable; order is priority, and the first one’s audio leads the output. With no -l at all, eng is kept.
  • -n, --no-language — keep tracks with no language tag.
  • --include-other-audio — keep non-default audio: commentary, descriptive audio, alternate mixes. Subtitle tracks flagged as commentary follow it too.
  • --video-codec, --audio-codec, --subtitle-codec — codecs to copy as they are. Repeatable.
  • --video-transcode, --audio-transcode — what a kept track becomes when it isn’t one of those.
  • --video-option, --audio-option — an extra FFmpeg option to pass when transcoding. Repeatable.
  • -d, --dry-run — print the operations and write nothing.
  • --skip-noops — leave a file alone if slimming wouldn’t change it.
  • --skip-verify — don’t re-read the output afterwards to check it.
  • --suppress-stderr — discard FFmpeg’s own chatter.
  • -h, --help — the whole list, printed by the tool itself.

The repeatable flags replace their defaults rather than adding to them. The first --audio-codec you pass clears the built-in list, so name every codec you want kept — not just the extra one.

Progress is written to standard error as a percentage, which leaves standard output clean for a pipe. Try --dry-run before turning a loop loose on a library.

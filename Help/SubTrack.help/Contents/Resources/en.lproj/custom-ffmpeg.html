Use an FFmpeg build of your own

The reason to do this is a specific one: you need an encoder the bundled build doesn’t have. Otherwise the bundled build is the better choice — it’s the one SubTrack is tested against, and it travels with the app.

Point SubTrack at a folder

  1. Choose SubTrack ▸ Settings (⌘,) and click FFmpeg.
  2. Under FFmpeg Location, select Custom….
  3. Click Auto-detect to have SubTrack find one for you, or Choose… to select the folder holding the binaries yourself.
  4. Check under FFmpeg Information that the version shown is the build you meant. An orange warning above it — This folder must contain ffmpeg and ffprobe — means SubTrack can’t use the folder; nothing there means it can.

Both binaries are required, and pointing at a folder holding only one of them is the usual mistake. SubTrack reads a file’s tracks with ffprobe and writes the slimmed file with ffmpeg, and the warning names whichever one is missing.

Let SubTrack find one

Auto-detect looks where a Mac usually keeps an FFmpeg — Homebrew on either prefix (/opt/homebrew/bin or /usr/local/bin), MacPorts (/opt/local/bin), and /usr/bin — runs each one it finds, and picks the newest. Between two builds of the same version it takes the one offering more encoders.

It doesn’t consult your shell’s PATH: an app launched from the Finder doesn’t inherit it, so the answer would be for an environment you never see. If your build lives somewhere else, use Choose….

If transcodes start failing afterwards

Builds vary enormously in what they were compiled with, and one that’s missing an encoder the bundled build has is a common way to break a queue that worked yesterday. Set FFmpeg Location back to Built-in — that undoes it completely.

After changing builds, select your files and choose Queue ▸ Re-scan Selected. The track plans on screen were worked out against the previous build, and re-scanning recomputes them against the new one.

The App Store version shows a fixed Built-in notice here instead of the choice. A sandboxed app may not run a binary a user hands it, so this is one of the things that version can’t do — see Choose between the two versions of SubTrack.

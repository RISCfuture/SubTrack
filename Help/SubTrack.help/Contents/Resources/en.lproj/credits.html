FFmpeg, licensing, and credits

Every track SubTrack copies, drops, or converts is handled by FFmpeg. SubTrack is the part that decides what should happen; FFmpeg is the part that does it. SubTrack itself is licensed under the GNU General Public License, version 2 or later.

Which FFmpeg licence applies to your copy

The two versions of SubTrack bundle different FFmpeg builds, and those builds are licensed differently.

  • Mac App Store — LGPL v2.1+. The bundled FFmpeg is built with no GPL-licensed components: no libx264, no libx265, no other GPL libraries. Video encoding goes through Apple VideoToolbox instead. This software uses libraries from the FFmpeg project under the LGPLv2.1.
  • Direct download — GPL v2+. The bundled FFmpeg is built with libx264 and libx265, which are licensed under the GPL v2 or later, so the combined work is distributed under the GPL v2+ as well. This software uses code of the FFmpeg project licensed under the GPLv2+.

libaom, the AV1 encoder, is in both builds — its BSD 2-Clause terms and the Alliance for Open Media Patent License 1.0 suit the LGPL build as well as the GPL one.

Read the notice for the build you’re running

  1. Choose SubTrack ▸ About SubTrack.
  2. Click License… for the full text, including copyright lines and a link to the licence itself.

The About window doesn’t list both possibilities — it shows the notice belonging to the copy in front of you, so what you read there is the licence you’re actually under.

Where the source is

SubTrack’s own source is at github.com/RISCfuture/SubTrack. Each GitHub release of the download version carries an FFmpeg sources archive next to the disk image — the corresponding source the GPL requires. The repository’s build script pins the exact version of FFmpeg, x264, x265, and libaom and builds them from source, so running it reproduces the bundled binaries.

FFmpeg source and licence information are also published at ffmpeg.org.

Other people’s work in SubTrack

Beyond FFmpeg, x264, x265, and libaom, SubTrack is built on these Swift packages:

  • DockProgress by Sindre Sorhus — MIT. Queue progress on the Dock icon.
  • GitHubUpdateChecker — MIT, in the download version only. It brings with it swift-markdown-ui, NetworkImage, swift-cmark, and swift-log.
  • sentry-cocoa — MIT. Crash reporting.
  • XCUITestKit — MIT. Used by the tests; not shipped in either version.

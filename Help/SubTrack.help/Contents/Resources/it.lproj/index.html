Aiuto di SubTrack

SubTrack rimuove le tracce audio e dei sottotitoli che non ti servono e lascia intatte, fino all’ultimo bit, quelle che vuoi tenere. Nulla viene ricodificato, quindi il rip di un Blu-ray di due ore si alleggerisce in pochi secondi, mantenendo esattamente la qualità di partenza.

Per iniziare

  • Alleggerire i video senza ricodificarli Copiare invece di convertire – e perché è così veloce.
  • Aggiungere video a una coda Trascina un film o una cartella piena di film.
  • Eseguire una coda e seguirne l’avanzamento Avvia, segui l’avanzamento e leggi i risultati.

Scegliere le tracce audio e dei sottotitoli

  • Scegliere quali lingue mantenere Lingue in ordine di priorità, commenti e tracce senza lingua.
  • Impostare i codec preferiti e i codec di destinazione L’unico caso in cui SubTrack converte una traccia.
  • Personalizzare il piano delle tracce di un file Quando un singolo file richiede un trattamento diverso dagli altri.
  • Leggere il piano completo di un file Ogni traccia che l’esecuzione scriverà e ogni traccia che rimuoverà.
  • Dare un nome ai file scritti da SubTrack I segnaposto e il nome del file di output.
  • Risolvere un conflitto di nomi I due modi in cui i nomi possono coincidere e come risolvere il conflitto.
  • Scegliere dove salvare i file alleggeriti La cartella di ogni coda oppure accanto a ogni sorgente.
  • Impostare la destinazione predefinita per le nuove code Cosa eredita una coda appena creata.

Salvare e riutilizzare le preimpostazioni

  • Salvare un insieme di regole come preimpostazione Quelle incluse in SubTrack e come salvare le tue regole.
  • Sincronizzare le preimpostazioni tra i tuoi Mac Come le sincronizza iCloud e cosa resta dov’è.
  • Se le preimpostazioni non si sincronizzano Accesso a iCloud non effettuato, restrizioni o un errore segnalato da iCloud.

Modificare le impostazioni di SubTrack

  • Impostare quanti file codificare contemporaneamente Quando il limite conta e quando no.
  • Usare una build di FFmpeg diversa Quale build stai usando e da dove proviene.
  • Usare una tua build di FFmpeg Quando ti serve un encoder che la build inclusa non ha.
  • Vedere cosa supporta una build di FFmpeg Tutti i contenitori e i codec che legge – e l’elenco più breve di quelli che scrive.
  • Installare lo strumento a riga di comando subtrack Alleggerire i file da Terminale.
  • Installare lo strumento subtrack Aggiungerlo al PATH, con o senza accesso da amministratore.
  • Cercare gli aggiornamenti di SubTrack Con quale frequenza e se includere le versioni preliminari.

Risolvere i problemi

  • Se un file non viene alleggerito Quale dei quattro problemi hai davanti e come usare il Registro attività.
  • Se SubTrack non riesce a leggere un file L’analisi non è riuscita prima ancora dell’alleggerimento.
  • Se il file sorgente è mancante Spostato, smontato o con un accesso salvato non più valido.
  • Se un’esecuzione parte e poi non riesce Un disco pieno, una destinazione scomparsa o un danno nel file sorgente.
  • Se un codec non può essere codificato La build in uso non ha un encoder per il codec di destinazione scelto.

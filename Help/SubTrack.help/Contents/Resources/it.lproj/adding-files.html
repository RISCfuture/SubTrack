Aggiungere video a una coda

Una coda è un elenco di file in attesa di essere alleggeriti, insieme alle regole che stabiliscono cosa mantenere di ciascuno. Puoi aggiungere file in tre modi.

Aggiungere file

  1. Trascina i video dal Finder nella finestra di SubTrack, oppure
  2. scegli File ▸ Aggiungi file… (⌘O) e selezionali, oppure
  3. fai clic su Aggiungi nella barra degli strumenti.

SubTrack legge ogni file appena arriva per scoprire cosa contiene: è il breve stato Analisi che vedi nella coda. Finché non termina, SubTrack non sa ancora cosa manterrà del file.

Aggiungere un’intera cartella

  1. Scegli File ▸ Aggiungi cartella… (⇧⌘O) oppure trascina una cartella nella finestra.
  2. Scegli la cartella e fai clic su Apri.

SubTrack esamina l’intera cartella, comprese le sottocartelle, e mette in coda ogni video che trova. Una stagione di episodi divisi in sottocartelle arriva con un solo gesto.

Rilasciare una cartella molto grande può richiedere qualche istante; SubTrack mostra l’avanzamento della ricerca. I file che non riconosce come video vengono ignorati senza avvisi, invece di essere messi in coda e poi dare errore.

Lavorare con più code

Una coda non è solo un elenco. Ognuna ha i propri file, le proprie regole di conservazione, la propria preimpostazione, la propria cartella di destinazione e il proprio formato del nome di output: così una coda di film in lingua straniera e una di serie TV in inglese possono avere esigenze del tutto diverse senza interferire l’una con l’altra.

  1. Scegli File ▸ Nuova coda (⌘N).
  2. Seleziona una coda nella barra laterale per lavorarci.
  3. Per rinominare o eliminare una coda, scegli File ▸ Rinomina coda… oppure Elimina coda.

Quando riapri SubTrack, le code ricompaiono esattamente come le avevi lasciate, compresi i file non ancora elaborati.

Se un file risulta mancante

SubTrack ricorda dove si trova ogni file sorgente. Se lo sposti o lo elimini dopo averlo messo in coda, la riga viene contrassegnata come mancante, invece di interrompere l’esecuzione a metà. Per maggiori informazioni, consulta Se il file sorgente è mancante.

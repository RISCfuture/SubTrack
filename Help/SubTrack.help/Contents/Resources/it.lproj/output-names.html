Dare un nome ai file scritti da SubTrack

SubTrack non modifica mai un file sorgente: ne scrive uno nuovo accanto. Il formato del nome di output stabilisce come si chiama il nuovo file.

Per cambiarlo, mostra l’Inspector (⌥⌘I), scegli la scheda Regole e modifica Nome di output. Ogni coda ha il proprio.

Comporre un nome con i segnaposto

Il formato è testo normale con dei segnaposto al posto dei dettagli di ciascun file:

  • {name} – il nome del file sorgente, senza l’estensione.
  • {n} – la posizione del file nella coda.

Così {name} (slimmed) trasforma The Third Man.mkv in The Third Man (slimmed).mkv.

L’estensione non fa mai parte del formato. Il file di output ha lo stesso contenitore della sorgente, quindi è SubTrack ad aggiungere l’estensione; un formato che provasse a cambiarla descriverebbe qualcosa che non può fare.

Scrivere una parentesi graffa letterale

Raddoppia una parentesi graffa per ottenerla così com’è: {{name}} produce il testo {name} invece del nome del file. Un segnaposto non riconosciuto, come {title}, viene lasciato com’è e compare identico nel nome: un errore di battitura dà un nome di file strano, ma non si perde nulla.

Quando due nomi coincidono

SubTrack non avvia una coda se i suoi nomi distruggerebbero un file, e i casi possibili sono due – ognuno con una soluzione rapida. Per maggiori informazioni, consulta Risolvere un conflitto di nomi.

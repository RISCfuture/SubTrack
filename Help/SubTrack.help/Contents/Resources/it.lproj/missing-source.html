Se il file sorgente è mancante

Una coda conserva un riferimento a ogni file, non una copia, e quel riferimento resta valido anche dopo aver chiuso SubTrack. Così una coda lasciata lì per tutta la notte può ritrovarsi con un file che è stato spostato, rinominato, eliminato o che si trova su un disco non ancora montato. La riga diventa rossa e riporta La sorgente è mancante.

Esiste anche una versione meno evidente dello stesso problema. Aggiungere un file è ciò che dà a SubTrack l’autorizzazione per raggiungerlo, e questa autorizzazione viene salvata in modo che continui a funzionare dopo un nuovo avvio. Gli accessi salvati possono diventare non validi: il file è esattamente dove l’hai lasciato, ma la riga indica che il riferimento salvato non è più valido o che SubTrack non ha l’autorizzazione per aprirlo.

Ripristinare il file

  1. Rimetti il file al suo posto: monta il disco, annulla la modifica del nome oppure recuperalo dal Cestino.
  2. Seleziona la riga e scegli Coda ▸ Rianalizza selezione.
  3. Se la riga è ancora segnalata, scegli Coda ▸ Rimuovi selezione (Elimina) e aggiungi di nuovo il file.

Il terzo passaggio è quello che elimina un accesso salvato non più valido, ed è per questo che è la soluzione di riferimento: aggiungere un file è ciò che concede l’accesso, quindi aggiungerlo di nuovo lo concede di nuovo. Rimuovere una riga non elimina mai nulla dal disco.

Impostare la destinazione predefinita per le nuove code

Scegli SubTrack ▸ Impostazioni (⌘,), fai clic su Generali, quindi su Cambia destinazione….

Le nuove code partono con questa destinazione. Le code già esistenti non vengono modificate: ognuna mantiene quella che le era stata assegnata, quindi puoi cambiarla in qualsiasi momento senza rischi.

Se non la imposti, le nuove code salvano i file accanto a ciascuna sorgente.

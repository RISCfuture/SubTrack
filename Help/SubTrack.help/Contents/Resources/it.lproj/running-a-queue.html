Eseguire una coda e seguirne l’avanzamento

Quando la coda mostra cosa manterrà ogni file, puoi eseguirla tutta oppure solo in parte.

Avviare l’alleggerimento

  1. Per eseguire tutto, scegli Coda ▸ Avvia tutto (⌘R).
  2. Per eseguire solo alcuni file, selezionali e scegli Coda ▸ Avvia selezione (⌘Invio).
  3. Per fermare l’esecuzione, scegli Coda ▸ Annulla tutto (⌘.).

Annullando, il lavoro in corso si interrompe e l’output parziale viene scartato. I file sorgente non vengono mai modificati: SubTrack scrive sempre e solo file nuovi.

Se Avvia è disattivato, due file della coda verrebbero scritti nella stessa posizione oppure uno sovrascriverebbe la propria sorgente. SubTrack non si avvia finché il problema non è risolto, perché in entrambi i casi un file andrebbe distrutto. Per maggiori informazioni, consulta Risolvere un conflitto di nomi.

Seguire l’avanzamento

Ogni riga in esecuzione mostra il proprio avanzamento, mentre la barra sotto la coda indica quanti elementi ci sono, quanti sono terminati e quanti sono in codifica in questo momento. Anche l’icona nel Dock riporta l’avanzamento complessivo, quindi puoi avviare un batch e passare ad altro.

I file che vengono solo copiati terminano quasi subito. Un file in cui va convertita una traccia richiede il tempo che serve alla conversione, ed è per questo che una coda può sembrare ferma su una sola riga mentre le altre scorrono veloci. Quella riga sta facendo un lavoro vero.

Leggere i risultati

La coda mostra per ogni file il numero di tracce e la dimensione prima e dopo, così vedi quanto è stato effettivamente risparmiato. La dimensione dell’output è definitiva solo quando un file è terminato; fino ad allora sul disco non c’è nulla da misurare.

Fai clic con il tasto destro sull’intestazione della coda per nascondere le colonne che non leggi e restituire la loro larghezza a Nome; fai di nuovo clic per riaverle. SubTrack ricorda la tua scelta. Il simbolo di stato e Nome restano sempre visibili.

La colonna di stato mostra un simbolo per ogni riga. Passaci sopra con il puntatore per leggerne il significato:

  • Un anello che ruota: il file viene analizzato oppure alleggerito.
  • Un segno di spunta: terminato.
  • Un triangolo di avviso: il file è mancante, l’esecuzione non è riuscita oppure la build di FFmpeg in uso non può fare ciò che chiedono le regole. Per maggiori informazioni, consulta Se un file non viene alleggerito.

Fare ordine

  • Coda ▸ Rimuovi completati rimuove le righe terminate e lascia le altre.
  • Coda ▸ Rimuovi selezione (Elimina) toglie i file dalla coda. Non elimina mai nulla dal disco.
  • Coda ▸ Rianalizza selezione rilegge una sorgente: è utile se hai sostituito il file o cambiato la build di FFmpeg usata da SubTrack.

Scegliere dove salvare i file alleggeriti

Ogni coda scrive i propri file di output da qualche parte: in una cartella che scegli tu oppure nella cartella in cui si trova già ogni file sorgente.

Impostare la destinazione di una coda

  1. Seleziona la coda nella barra laterale.
  2. Fai clic su Cambia… nella barra sopra la coda.
  3. Scegli una cartella e fai clic su Apri.

Tutti i file della coda vengono scritti in quella cartella, qualunque sia la cartella di provenienza. È quello che ti serve quando vuoi raccogliere in un unico posto i risultati di sorgenti sparse.

Salvare invece accanto a ogni sorgente

In una coda senza destinazione, ogni file alleggerito viene salvato nella stessa cartella del file da cui proviene. Gli episodi di una stagione restano così nelle rispettive cartelle, invece di essere riuniti tutti in una.

È l’impostazione predefinita, ed è il motivo per cui la barra della destinazione può indicare Verranno salvati accanto a ogni sorgente invece del nome di una cartella.

Salvare accanto alla sorgente è la configurazione che più facilmente causa un conflitto di nomi, perché l’output finisce nella stessa cartella dell’input. Se il tuo formato produce esattamente il nome della sorgente, SubTrack non avvia l’esecuzione per non sovrascriverla. Per maggiori informazioni, consulta Risolvere un conflitto di nomi.

Impostare la destinazione predefinita per le nuove code

Ogni nuova coda parte con una destinazione propria, che imposti una volta sola in Impostazioni. Per maggiori informazioni, consulta Impostare la destinazione predefinita per le nuove code. Se la modifichi, le code già esistenti non cambiano.

Se SubTrack non riesce a scrivere in una cartella

macOS concede a SubTrack l’accesso alle cartelle che scegli, e l’accesso viene ricordato a ogni apertura successiva. Se una destinazione non è più disponibile, per esempio perché un disco esterno non è collegato o una cartella è stata spostata o eliminata, l’esecuzione si interrompe invece di scrivere in un posto inatteso.

Scegliere di nuovo la cartella ripristina l’accesso. Se il problema riguarda un file sorgente e non una destinazione, consulta Se il file sorgente è mancante.

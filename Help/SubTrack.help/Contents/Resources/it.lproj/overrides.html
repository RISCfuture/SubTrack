Personalizzare il piano delle tracce di un file

Le regole di conservazione valgono per l’intera coda. Quando un file richiede un trattamento diverso, per esempio una traccia etichettata male o un documentario di cui vuoi tenere il commento, puoi intervenire solo su quel file.

Leggere il piano

  1. Seleziona un file nella coda.
  2. Mostra l’Inspector (⌥⌘I) e scegli la scheda Personalizzazione (⌥⌘2).

Il menu delle tracce elenca tutte le tracce del file. Le voci attenuate sono quelle che verranno rimosse; le altre verranno mantenute. Scegli una traccia per vedere cosa le succederà e perché.

Per leggere l’intero file in una volta anziché una traccia alla volta, consulta Leggere il piano completo di un file. È il modo più rapido per verificare che le regole facciano ciò che intendevi prima di applicarle a un’intera coda.

Modificare una traccia

Scegli una traccia, poi decidi cosa farne: mantenerla, rimuoverla o convertirla in un codec specifico.

Una cosa da sapere prima di procedere. Modificando una sola traccia, l’intero file passa a un piano proprio. Tutte le altre tracce restano fissate esattamente come le avevano stabilite le regole in quel momento e, da allora in poi, il file non segue più le regole della coda. Se in seguito modifichi le regole, questo file non si aggiornerà.

Di solito è ciò che vuoi, dato che hai scelto il file di proposito, ma significa che una personalizzazione impostata tempo fa e dimenticata ignorerà, senza avvisarti, le modifiche successive alle regole.

Tornare alle regole

Fai clic su Torna alle regole. Il file abbandona il proprio piano e segue di nuovo le regole della coda, comprese le modifiche fatte nel frattempo. Il pulsante compare solo quando un file ha davvero una personalizzazione, quindi serve anche a capire se ne è impostata una.

Dare a un file un nome diverso

La stessa scheda imposta un nome di output solo per questo file, al posto del formato del nome di output della coda. Per maggiori informazioni, consulta Dare un nome ai file scritti da SubTrack.

Se rianalizzi un file (Coda ▸ Rianalizza selezione), le sue tracce vengono lette di nuovo dal disco. Una personalizzazione che si riferiva a una traccia non più presente non può essere applicata, quindi controlla il piano dopo aver sostituito un file sorgente.

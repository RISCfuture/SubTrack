Risolvere un conflitto di nomi

SubTrack non avvia una coda i cui nomi distruggerebbero un file, e questo può succedere in due soli modi.

Due file verrebbero scritti nella stessa posizione

Il formato non distingue due sorgenti, di solito perché hanno lo stesso nome in cartelle diverse, come Show.mkv in una cartella Stagione 1 e in una Stagione 2. Il file terminato per ultimo sovrascriverebbe l’altro.

Per risolvere, fai in modo che il formato produca nomi distinti. Aggiungere {n} è il metodo più rapido; assegnare a un file un nome tutto suo nella scheda Personalizzazione è il metodo più preciso. In alternativa, invia le code a cartelle diverse.

Un file sovrascriverebbe la propria sorgente

Il formato produce esattamente il nome della sorgente e la cartella di destinazione è la cartella in cui si trova la sorgente: SubTrack dovrebbe quindi scrivere sopra il file che sta leggendo.

Per risolvere, aggiungi qualcosa al formato, come {name} (slimmed), oppure scegli una cartella di destinazione diversa. Per maggiori informazioni, consulta Scegliere dove salvare i file alleggeriti.

L’avviso indica quali file sono coinvolti, così puoi vedere quali sono in conflitto senza dover indovinare. Avvia torna disponibile non appena non ci sono più due destinazioni uguali.

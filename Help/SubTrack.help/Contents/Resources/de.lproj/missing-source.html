Wenn die Quelldatei fehlt

Eine Warteschlange enthält zu jeder Datei einen Verweis und keine Kopie, und dieser Verweis bleibt beim Beenden von SubTrack erhalten. Eine Warteschlange, die du über Nacht stehen lässt, kann also auf eine Datei treffen, die verschoben, umbenannt oder gelöscht wurde oder die auf einer Festplatte liegt, die gerade nicht angeschlossen ist. Die Zeile wird rot und meldet Die Quelle fehlt.

Es gibt eine weniger offensichtliche Variante desselben Problems. Durch das Hinzufügen einer Datei erhält SubTrack die Berechtigung, auf sie zuzugreifen, und diese Berechtigung wird gespeichert, damit sie auch nach einem Neustart noch gilt. Eine gespeicherte Zugriffsberechtigung kann ungültig werden: Die Datei liegt genau dort, wo du sie gelassen hast, aber die Zeile meldet, dass die gespeicherte Referenz nicht mehr gültig ist oder dass SubTrack keine Berechtigung hat, sie zu öffnen.

Die Datei wiederherstellen

  1. Lege die Datei zurück – schließe die Festplatte an, mache die Umbenennung rückgängig, hole sie aus dem Papierkorb zurück.
  2. Wähle die Zeile aus und wähle Warteschlange ▸ Auswahl erneut analysieren.
  3. Wenn sie weiterhin markiert ist, wähle Warteschlange ▸ Auswahl entfernen (⌫) und füge die Datei erneut hinzu.

Der dritte Schritt erneuert eine ungültig gewordene Zugriffsberechtigung, und deshalb ist er die Standardempfehlung: Das Hinzufügen einer Datei erteilt den Zugriff, also erteilt ihn das erneute Hinzufügen erneut. Das Entfernen einer Zeile löscht nie etwas von der Festplatte.

Nach SubTrack-Updates suchen

Die Download-Version von SubTrack hält sich selbst aktuell: Sie fragt bei GitHub nach, ob es ein neueres Release gibt, und bietet es dir an.

Wenn du keinen Tab Updates siehst, verwendest du die App-Store-Version. Sie hat überhaupt keine Update-Einstellungen, weil der App Store diese Kopie aktuell hält. Weitere Informationen: Zwischen den beiden Versionen von SubTrack wählen.

Festlegen, wie oft SubTrack sucht

  1. Wähle SubTrack ▸ Einstellungen (⌘,) und klicke auf Updates.
  2. Stelle Nach Updates suchen auf Stündlich, Täglich, Wöchentlich oder Nie.
  3. Aktiviere Vorabversionen einbeziehen, wenn du auch Beta-Builds haben möchtest.

Der Zeitplan läuft nur, solange SubTrack geöffnet ist – im Hintergrund läuft nichts weiter, wenn die App beendet ist. Eine Vorabversion ist ein Release, das auf GitHub als solches markiert ist: ein Build, der zum Testen veröffentlicht wird, bevor er als endgültig gilt. Lässt du den Schalter ausgeschaltet, werden dir nur fertige Releases angeboten.

Zuletzt geprüft zeigt, wann die letzte Suche beendet wurde, oder einen Strich, wenn noch keine stattgefunden hat. Jetzt suchen startet sofort eine Suche und meldet in jedem Fall das Ergebnis; die Taste ist abgeblendet, solange bereits eine Suche läuft. Dieselbe Suche steht jederzeit unter SubTrack ▸ Nach Updates suchen … zur Verfügung.

Eine übersprungene Version erneut anbieten

Wenn SubTrack dir ein Update anbietet, ist eine der Tasten in diesem Hinweis Diese Version überspringen. Wählst du sie, wird dieses Release nie wieder erwähnt – weder bei der zeitgesteuerten Suche noch bei Jetzt suchen, das dir dann munter mitteilt, du seist auf dem neuesten Stand. Das Überspringen geschieht dort, nicht in diesem Bereich.

Übersprungene Versionen zurücksetzen vergisst alle Versionen, die du übersprungen hast, sodass jede wieder angeboten wird. Die Taste ist abgeblendet, solange du nichts übersprungen hast. Wenn du weißt, dass es eine neuere Version gibt, und SubTrack beharrlich behauptet, du seist auf dem neuesten Stand, ist das die richtige Taste.

Eine Suche ist eine einzige Anfrage an die öffentliche Release-Liste von GitHub. Sie sendet nichts über dich, deinen Mac oder deine Dateien. Weitere Informationen: Was SubTrack sendet und was nicht.

Dar nombre a los archivos que escribe SubTrack

SubTrack nunca modifica un archivo de origen – escribe uno nuevo junto a él. El formato del nombre de salida decide cómo se llama ese archivo nuevo.

Para cambiarlo, muestra el inspector (⌥⌘I), selecciona Reglas y edita Nombre de salida. Cada cola tiene el suyo.

Componer un nombre con marcadores

El formato es texto normal con marcadores que representan los datos de cada archivo:

  • {name} – el nombre del archivo de origen, sin su extensión.
  • {n} – la posición del archivo en la cola.

Así, {name} (slimmed) convierte The Third Man.mkv en The Third Man (slimmed).mkv.

La extensión nunca forma parte del formato. El resultado conserva el mismo contenedor que el origen, de modo que SubTrack añade la extensión por sí mismo; un formato que intentara cambiarla describiría algo que no puede hacer.

Escribir una llave literal

Duplica una llave para que se escriba tal cual: {{name}} produce el texto {name} en lugar del nombre del archivo. Un marcador desconocido, como {title}, se deja sin tocar y aparece tal cual en el nombre, de modo que un error de escritura da un nombre de archivo extraño, pero no se pierde nada.

Cuando dos nombres coinciden

SubTrack se niega a iniciar una cola cuyos nombres destruirían un archivo, y esto solo puede ocurrir de dos maneras – ambas fáciles de resolver. Para obtener más información, consulta Resolver un conflicto de nombres.

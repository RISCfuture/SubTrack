Voir ce que prend en charge une version de FFmpeg

Cliquez sur Formats pris en charge dans Réglages ▸ FFmpeg. La fenêtre liste les Conteneurs, les Codecs vidéo, les Codecs audio et les Codecs de sous-titres de la version utilisée, chaque groupe pouvant être replié et chaque ligne indiquant l’identifiant du format et son nom complet. Saisissez du texte dans le champ Filtrer pour restreindre tous les groupes à la fois.

Décoder n’est pas encoder

Chaque ligne porte deux repères, qui n’ont pas le même sens. Les conteneurs sont marqués Lecture / Écriture, les codecs Décodage / Encodage – et lire n’est pas écrire. Une version peut décoder parfaitement un codec sans pouvoir en produire une seule image. C’est normal : pratiquement toutes les versions lisent plus de formats qu’elles n’en écrivent.

Cette asymétrie explique précisément l’avertissement indiquant que le FFmpeg actuel ne peut pas encoder un codec cible que vous avez choisi. Filtrez sur le codec, regardez le second repère, et vous le verrez.

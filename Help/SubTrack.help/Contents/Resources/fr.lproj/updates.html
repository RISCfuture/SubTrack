Rechercher les mises à jour de SubTrack

La version téléchargeable de SubTrack se tient à jour toute seule : elle demande à GitHub si une version plus récente existe et vous la propose.

Si vous ne voyez pas d’onglet Mises à jour, vous utilisez la version App Store. Elle n’a aucun réglage de mise à jour, car l’App Store maintient cet exemplaire à jour. Pour en savoir plus, consultez Choisir entre les deux versions de SubTrack.

Définir la fréquence de recherche

  1. Choisissez SubTrack ▸ Réglages (⌘,) et cliquez sur Mises à jour.
  2. Réglez Rechercher les mises à jour sur Toutes les heures, Tous les jours, Chaque semaine ou Jamais.
  3. Activez Inclure les versions préliminaires si vous voulez aussi recevoir les versions bêta.

La recherche programmée n’a lieu que lorsque SubTrack est ouvert : aucun programme auxiliaire ne tourne en arrière-plan quand l’app est quittée. Une version préliminaire est une version signalée comme telle sur GitHub, c’est-à-dire publiée pour être testée avant d’être déclarée définitive. Si vous laissez le réglage désactivé, seules les versions définitives vous sont proposées.

Dernière vérification indique quand la dernière recherche s’est terminée, ou un tiret si aucune n’a eu lieu. Rechercher maintenant en lance une immédiatement et vous donne le résultat dans tous les cas ; le bouton est grisé tant qu’une recherche est déjà en cours. Cette même recherche est disponible à tout moment dans SubTrack ▸ Rechercher les mises à jour….

Revenir sur une version ignorée

Quand SubTrack vous propose une mise à jour, l’un des boutons de la fenêtre est Skip This Version. Si vous le choisissez, cette version n’est plus jamais mentionnée, ni par la recherche programmée, ni par Rechercher maintenant, qui vous répondra sans hésiter que vous êtes à jour. L’ignorer se fait dans cette fenêtre, pas dans ce panneau.

Réinitialiser les versions ignorées oublie toutes les versions que vous avez ignorées, qui vous sont alors proposées de nouveau. Le bouton est grisé tant que vous n’avez rien ignoré. Si vous savez qu’une version plus récente existe et que SubTrack affirme que vous êtes à jour, c’est ce bouton qu’il vous faut.

Une recherche consiste en une seule requête vers la liste publique des versions de GitHub. Elle n’envoie rien à votre sujet, ni sur votre Mac, ni sur vos fichiers. Pour en savoir plus, consultez Ce que SubTrack envoie, et ce qu’il n’envoie pas.

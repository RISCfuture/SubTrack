Résoudre un conflit de nom

SubTrack refuse de lancer une file d’attente dont les noms détruiraient un fichier, et cela ne peut arriver que de deux façons.

Deux fichiers seraient écrits au même endroit

Le format ne distingue pas deux sources, le plus souvent parce qu’elles portent le même nom dans des dossiers différents, comme Show.mkv dans un dossier Saison 1 et dans un dossier Saison 2. Le fichier terminé en dernier écraserait l’autre.

Pour y remédier, faites en sorte que le format produise des noms distincts. Ajouter {n} est le moyen le plus rapide ; donner son propre nom à un fichier dans l’onglet Personnalisation est le moyen le plus précis. Vous pouvez aussi envoyer les files d’attente vers des dossiers différents.

Un fichier écraserait sa propre source

Le format produit exactement le nom de la source, et le dossier de destination est celui où se trouve la source : SubTrack devrait donc écrire par-dessus le fichier même qu’il est en train de lire.

Pour y remédier, ajoutez quelque chose au format, par exemple {name} (slimmed), ou choisissez un autre dossier de destination. Pour en savoir plus, consultez Choisir où enregistrer les fichiers allégés.

L’avertissement indique les fichiers concernés, ce qui vous permet de voir lesquels sont en conflit sans avoir à deviner. Le bouton Démarrer redevient disponible dès que deux fichiers de sortie n’entrent plus en collision.

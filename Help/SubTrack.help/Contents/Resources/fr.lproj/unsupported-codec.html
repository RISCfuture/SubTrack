Si un codec ne peut pas être encodé

SubTrack vous avertit parfois que le FFmpeg actuel ne peut pas encoder un codec que vous avez choisi comme codec cible. Décider de convertir est une chose, disposer de l’encodeur nécessaire en est une autre.

Les deux raisons

  • Vous utilisez la version App Store. Elle intègre une version de FFmpeg sans les encodeurs logiciels H.264 et H.265, car les règles de l’App Store n’autorisent pas leur licence. Choisissez un codec cible que cette version prend en charge, ou utilisez la version téléchargeable. Pour en savoir plus, consultez Choisir entre les deux versions de SubTrack.
  • Vous avez indiqué à SubTrack votre propre FFmpeg, et cette version a été compilée sans l’encodeur. Le contenu des versions varie énormément. Revenez à Intégré dans Réglages ▸ FFmpeg, ou installez une version qui inclut l’encodeur dont vous avez besoin. Pour en savoir plus, consultez Utiliser votre propre version de FFmpeg.

Pour voir précisément ce que le FFmpeg utilisé peut lire et écrire, ouvrez Réglages ▸ FFmpeg et cliquez sur Formats pris en charge.

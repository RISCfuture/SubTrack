Exécuter une file d’attente et suivre sa progression

Une fois que la file d’attente indique ce que chaque fichier va conserver, vous pouvez l’exécuter en entier ou en partie.

Lancer l’allègement

  1. Pour tout exécuter, choisissez File d’attente ▸ Tout démarrer (⌘R).
  2. Pour n’exécuter que certains fichiers, sélectionnez-les et choisissez File d’attente ▸ Démarrer la sélection (⌘Retour).
  3. Pour arrêter, choisissez File d’attente ▸ Tout annuler (⌘.).

L’annulation interrompt le travail en cours et supprime le fichier partiel. Vos fichiers source ne sont jamais modifiés : SubTrack n’écrit que de nouveaux fichiers.

Si Démarrer est grisé, c’est que deux fichiers de la file d’attente seraient écrits au même endroit, ou que l’un d’eux écraserait sa propre source. SubTrack ne démarre pas tant que le problème n’est pas résolu, car dans les deux cas un fichier serait détruit. Pour en savoir plus, consultez Résoudre un conflit de nom.

Suivre la progression

Chaque ligne en cours affiche sa propre progression, et la barre située sous la file d’attente indique le nombre d’éléments, le nombre d’éléments terminés et le nombre d’éléments en cours d’encodage. L’icône du Dock reflète aussi la progression globale : vous pouvez donc lancer un lot et passer à autre chose.

Les fichiers qui sont simplement copiés se terminent presque instantanément. Un fichier dont une piste doit être convertie prend le temps que dure cette conversion, ce qui explique qu’une file d’attente puisse sembler bloquée sur une seule ligne pendant que les autres défilent. Cette ligne travaille bel et bien.

Lire les résultats

La file d’attente indique, pour chaque fichier, le nombre de pistes et la taille avant et après, afin que vous voyiez ce que l’exécution vous a réellement fait gagner. La taille du fichier de sortie n’est connue qu’une fois le fichier terminé ; avant cela, il n’y a rien à mesurer sur le disque.

Faites un clic droit sur l’en-tête de la file d’attente pour masquer une colonne que vous ne lisez pas et rendre sa largeur à Nom ; faites de nouveau un clic droit pour la réafficher. SubTrack mémorise votre choix. Le symbole d’état et Nom restent toujours affichés.

La colonne d’état affiche un symbole par ligne. Placez le pointeur dessus pour en lire la signification :

  • Un anneau qui tourne : le fichier est en cours d’analyse ou d’allègement.
  • Une coche : le fichier est terminé.
  • Un triangle d’avertissement : le fichier est introuvable, l’exécution a échoué ou le FFmpeg actuel ne sait pas faire ce que demandent les règles. Pour en savoir plus, consultez Si un fichier ne peut pas être allégé.

Nettoyer

  • File d’attente ▸ Retirer les éléments terminés retire les lignes terminées et laisse les autres.
  • File d’attente ▸ Retirer la sélection (Supprimer) retire des fichiers de la file d’attente. Rien n’est jamais supprimé du disque.
  • File d’attente ▸ Réanalyser la sélection relit une source, ce qui est utile si vous avez remplacé le fichier ou changé le FFmpeg utilisé par SubTrack.

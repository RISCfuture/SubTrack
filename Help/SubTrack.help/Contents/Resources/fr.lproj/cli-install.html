Installer l’outil subtrack

  1. Choisissez SubTrack ▸ Réglages (⌘,) et cliquez sur CLI.
  2. Cliquez sur Installer…
  3. Choisissez un dossier qui figure déjà dans votre PATH. Le panneau s’ouvre sur /usr/local/bin ; un dossier bin dans votre dossier de départ convient tout aussi bien et n’exige aucun accès administrateur.

La ligne Statut affiche alors le chemin complet où l’outil a été placé, avec un bouton Afficher qui le sélectionne dans le Finder.

Si le dossier exige un accès administrateur

Si le dossier n’est pas accessible en écriture – ce qui est généralement le cas de /usr/local/bin –, SubTrack ne vous demande pas votre mot de passe d’administrateur. Il n’a pas d’assistant privilégié à qui le confier, et une app qui réclame votre mot de passe pour copier un fichier est une habitude qu’il vaut mieux ne pas encourager. Le volet affiche Ce dossier nécessite un accès administrateur – exécutez plutôt ceci. ainsi que la commande sudo cp exacte, avec un bouton Copier. Collez-la dans le Terminal et authentifiez-vous-y, là où vous voyez ce que vous autorisez. Copier la commande d’installation fait la même chose sans ouvrir d’abord le panneau, pour la destination /usr/local/bin.

Une installation que vous effectuez vous-même est bien réelle, mais SubTrack ne l’a pas réalisée et n’en a pas connaissance : Statut continue d’indiquer Non installé. Vérifiez-la avec which subtrack.

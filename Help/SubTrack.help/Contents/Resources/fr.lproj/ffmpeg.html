Utiliser une autre version de FFmpeg

SubTrack travaille en pilotant FFmpeg, dont une version signée et autonome est incluse dans l’app. Il n’utilise rien de ce que vous avez installé vous-même, et il n’y a rien à configurer. La plupart des utilisateurs n’ouvrent jamais ce volet.

Vous y viendrez pour l’une de ces deux raisons : savoir quelle version de FFmpeg vous utilisez réellement ou, dans la version téléchargeable, en utiliser une de votre choix.

Voir quelle version de FFmpeg est utilisée

  1. Choisissez SubTrack ▸ Réglages… (⌘,) et cliquez sur FFmpeg.
  2. Lisez Version sous Informations sur FFmpeg.

SubTrack obtient cette version en exécutant le programme FFmpeg qu’il a retenu. C’est donc un reflet exact de ce qui est réellement exécuté. Si un avertissement s’affiche à la place d’une version, ce programme n’a pas pu être exécuté du tout, et rien ne sera encodé dans la file d’attente tant que le problème n’est pas résolu.

Utiliser votre propre version de FFmpeg

Il n’y a qu’une raison de le faire : vous avez besoin d’un encodeur que la version intégrée n’a pas. Sinon, la version intégrée est préférable – c’est celle avec laquelle SubTrack est testé, et elle est livrée avec l’app.

Indiquer un dossier à SubTrack

  1. Choisissez SubTrack ▸ Réglages (⌘,) et cliquez sur FFmpeg.
  2. Sous Emplacement de FFmpeg, sélectionnez Personnalisé…
  3. Cliquez sur Détecter automatiquement pour que SubTrack en trouve un, ou sur Choisir… pour sélectionner vous-même le dossier qui contient les binaires.
  4. Vérifiez sous Informations sur FFmpeg que la version affichée correspond à la version voulue. Un avertissement orange au-dessus – Ce dossier doit contenir ffmpeg et ffprobe – signifie que SubTrack ne peut pas utiliser le dossier ; s’il n’y en a pas, c’est que le dossier convient.

Les deux binaires sont requis, et l’erreur la plus courante consiste à indiquer un dossier qui n’en contient qu’un. SubTrack lit les pistes d’un fichier avec ffprobe et écrit le fichier allégé avec ffmpeg ; l’avertissement nomme celui qui manque.

Laisser SubTrack en trouver un

Détecter automatiquement cherche aux endroits où un Mac range habituellement FFmpeg – Homebrew, sous l’un ou l’autre préfixe (/opt/homebrew/bin ou /usr/local/bin), MacPorts (/opt/local/bin) et /usr/bin –, exécute chacun de ceux qu’il trouve et retient le plus récent. Entre deux exécutables portant le même numéro de version, il prend celui qui offre le plus d’encodeurs.

Il ne consulte pas le PATH de votre shell : une app lancée depuis le Finder ne l’hérite pas, de sorte que la réponse concernerait un environnement que vous ne voyez jamais. Si votre FFmpeg se trouve ailleurs, utilisez Choisir…

Si les transcodages échouent ensuite

Les versions varient énormément selon les options de compilation, et une version à laquelle il manque un encodeur que la version intégrée possède est une cause fréquente de panne dans une file d’attente qui fonctionnait la veille. Remettez Emplacement de FFmpeg sur Intégré : cela annule complètement le changement.

Après avoir changé de version de FFmpeg, sélectionnez vos fichiers et choisissez File d’attente ▸ Réanalyser la sélection. Les plans de pistes affichés ont été établis avec l’ancienne version ; la réanalyse les recalcule avec la nouvelle.

La version App Store affiche ici un avis fixe Intégré à la place du choix. Une app sandboxée ne peut pas exécuter un binaire fourni par l’utilisateur, c’est donc l’une des choses que cette version ne sait pas faire. Pour en savoir plus, consultez Choisir entre les deux versions de SubTrack.

FFmpeg, licences et crédits

Chaque piste que SubTrack copie, retire ou convertit est traitée par FFmpeg. SubTrack décide de ce qui doit se passer ; FFmpeg l’exécute. SubTrack est lui-même distribué sous la licence publique générale GNU (GPL), version 2 ou ultérieure.

Licence FFmpeg applicable à votre exemplaire

Les deux versions de SubTrack intègrent des versions de FFmpeg différentes, et ces versions sont placées sous des licences différentes.

  • Mac App Store – LGPL v2.1+. Le FFmpeg intégré est compilé sans aucun composant sous licence GPL : ni libx264, ni libx265, ni aucune autre bibliothèque GPL. L’encodage vidéo passe par Apple VideoToolbox. Ce logiciel utilise des bibliothèques du projet FFmpeg sous licence LGPLv2.1.
  • Téléchargement direct – GPL v2+. Le FFmpeg intégré est compilé avec libx264 et libx265, qui sont placés sous la licence GPL v2 ou ultérieure ; l’œuvre combinée est donc elle aussi distribuée sous GPL v2+. Ce logiciel utilise du code du projet FFmpeg sous licence GPLv2+.

libaom, l’encodeur AV1, figure dans les deux versions – ses conditions BSD 2-Clause et la licence de brevets Alliance for Open Media Patent License 1.0 conviennent aussi bien à la version LGPL qu’à la version GPL.

Lire l’avis correspondant à votre version

  1. Choisissez SubTrack ▸ À propos de SubTrack.
  2. Cliquez sur Licence… pour afficher le texte intégral, y compris les mentions de copyright et un lien vers la licence elle-même.

La fenêtre « À propos » ne présente pas les deux possibilités : elle affiche l’avis qui correspond à l’exemplaire que vous utilisez. La licence que vous lisez est donc bien celle qui vous engage.

Où trouver le code source

Le code source de SubTrack est disponible sur github.com/RISCfuture/SubTrack. Chaque version GitHub de la version téléchargeable comprend, à côté de l’image disque, une archive des sources de FFmpeg : le code source correspondant que la GPL exige. Le script de compilation du dépôt fixe les versions exactes de FFmpeg, x264, x265 et libaom et les compile à partir des sources ; en l’exécutant, vous obtenez donc les mêmes binaires que ceux qui sont intégrés.

Le code source et les informations de licence de FFmpeg sont également publiés sur ffmpeg.org.

Travaux de tiers dans SubTrack

Outre FFmpeg, x264, x265 et libaom, SubTrack repose sur les packages Swift suivants :

  • DockProgress de Sindre Sorhus – MIT. Affiche la progression de la file d’attente sur l’icône du Dock.
  • GitHubUpdateChecker – MIT, dans la version téléchargeable uniquement. Il apporte avec lui swift-markdown-ui, NetworkImage, swift-cmark et swift-log.
  • sentry-cocoa – MIT. Rapports d’incident.
  • XCUITestKit – MIT. Utilisé par les tests ; n’est livré dans aucune des deux versions.

Ajouter des vidéos à une file d’attente

Une file d’attente est une liste de fichiers à alléger, accompagnée des règles qui déterminent ce que chacun conserve. Vous pouvez y ajouter des fichiers de trois façons.

Ajouter des fichiers

  1. Faites glisser des vidéos depuis le Finder vers la fenêtre de SubTrack, ou
  2. choisissez Fichier ▸ Ajouter des fichiers… (⌘O) et sélectionnez-les, ou
  3. cliquez sur Ajouter dans la barre d’outils.

SubTrack lit chaque fichier dès son arrivée pour savoir ce qu’il contient. C’est l’état bref Analyse dans la file d’attente. Tant qu’il n’est pas terminé, SubTrack ne sait pas encore ce que le fichier conservera.

Ajouter un dossier entier

  1. Choisissez Fichier ▸ Ajouter un dossier… (⇧⌘O), ou faites glisser un dossier vers la fenêtre.
  2. Choisissez le dossier et cliquez sur Ouvrir.

SubTrack parcourt tout le dossier, sous-dossiers compris, et place en file d’attente chaque vidéo trouvée. Une saison d’épisodes rangés dans un sous-dossier par épisode arrive en une seule opération.

Le dépôt d’un dossier volumineux peut prendre un moment. SubTrack affiche sa progression pendant la recherche. Les fichiers qu’il ne reconnaît pas comme des vidéos sont ignorés sans message, au lieu d’être mis en file d’attente puis en échec.

Travailler avec plusieurs files d’attente

Une file d’attente est bien plus qu’une liste. Chacune a ses propres fichiers, ses propres règles de conservation, son propre préréglage, son propre dossier de destination et sa propre convention de nommage. Ainsi, une file de films en version originale et une file de séries télévisées en anglais peuvent avoir des besoins totalement différents sans se gêner.

  1. Choisissez Fichier ▸ Nouvelle file d’attente (⌘N).
  2. Sélectionnez une file d’attente dans la barre latérale pour travailler dedans.
  3. Pour en renommer ou en supprimer une, choisissez Fichier ▸ Renommer la file d’attente… ou Supprimer la file d’attente.

Les files d’attente sont restaurées telles que vous les avez laissées à la prochaine ouverture de SubTrack, y compris les fichiers qui n’avaient pas encore été traités.

Si un fichier a disparu

SubTrack mémorise l’emplacement de chaque fichier source. Si vous déplacez ou supprimez un fichier après l’avoir mis en file d’attente, sa ligne est signalée comme introuvable, au lieu d’échouer en cours d’exécution. Pour en savoir plus, consultez Si le fichier source est introuvable.

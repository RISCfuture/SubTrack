Nommer les fichiers écrits par SubTrack

SubTrack ne modifie jamais un fichier source – il écrit un nouveau fichier à côté. Le format de nom détermine comment ce nouveau fichier s’appelle.

Pour le modifier, affichez l’inspecteur (⌥⌘I), choisissez Règles, puis modifiez Nom de sortie. Chaque file d’attente a le sien.

Composer un nom avec des balises

Le format est du texte ordinaire dans lequel des balises représentent les informations propres à chaque fichier :

  • {name} – le nom du fichier source, sans son extension.
  • {n} – la position du fichier dans la file d’attente.

Ainsi, {name} (slimmed) transforme The Third Man.mkv en The Third Man (slimmed).mkv.

L’extension ne fait jamais partie du format. Le fichier de sortie garde le même conteneur que la source : SubTrack ajoute donc lui-même l’extension, et un format qui essaierait de la modifier décrirait quelque chose d’impossible.

Écrire une accolade littérale

Doublez une accolade pour qu’elle soit prise telle quelle : {{name}} produit le texte {name} et non le nom du fichier. Une balise non reconnue comme {title} est laissée telle quelle et apparaît ainsi dans le nom ; une faute de frappe donne donc un nom de fichier inattendu, mais rien n’est perdu.

Quand deux noms entrent en conflit

SubTrack refuse de démarrer une file d’attente dont les noms détruiraient un fichier. Cela ne peut arriver que de deux façons, et chacune se corrige facilement. Pour en savoir plus, consultez Résoudre un conflit de nom.

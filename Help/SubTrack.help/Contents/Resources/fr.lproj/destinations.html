Choisir où enregistrer les fichiers allégés

Chaque file d’attente écrit ses fichiers quelque part : soit dans un dossier que vous choisissez, soit dans le dossier où se trouve déjà chaque fichier source.

Définir la destination d’une file d’attente

  1. Sélectionnez la file d’attente dans la barre latérale.
  2. Cliquez sur Modifier… dans la barre située au-dessus de la file d’attente.
  3. Choisissez un dossier, puis cliquez sur Ouvrir.

Tous les fichiers de cette file d’attente y sont écrits, quel que soit leur dossier d’origine. C’est pratique pour rassembler en un seul endroit les résultats de sources dispersées.

Enregistrer plutôt à côté de chaque source

Quand aucune destination n’est définie pour une file d’attente, chaque fichier allégé est enregistré dans le dossier du fichier dont il provient. Les épisodes d’une série restent ainsi répartis dans leurs dossiers de saison au lieu d’être regroupés dans un seul.

C’est le réglage par défaut, et c’est pourquoi la barre de destination peut afficher Enregistrement à côté de chaque source au lieu du nom d’un dossier.

Enregistrer à côté de la source est la configuration qui risque le plus de provoquer un conflit de nom, car le fichier écrit se retrouve dans le même dossier que le fichier d’origine. Si votre format produit exactement le nom de la source, SubTrack refuse de démarrer plutôt que de l’écraser. Pour en savoir plus, consultez Résoudre un conflit de nom.

Définir la destination par défaut des nouvelles files d’attente

Chaque nouvelle file d’attente démarre avec sa propre destination, définie une fois pour toutes dans les Réglages. Pour en savoir plus, consultez Définir la destination par défaut des nouvelles files d’attente. Modifier ce réglage n’a aucun effet sur les files d’attente existantes.

Si SubTrack ne peut pas écrire dans un dossier

macOS donne à SubTrack l’accès aux dossiers que vous choisissez, et cet accès est conservé d’un lancement à l’autre. Si une destination devient indisponible (disque externe non monté, dossier déplacé ou supprimé), l’exécution s’arrête au lieu d’écrire à un endroit inattendu.

Choisissez à nouveau le dossier pour rétablir l’accès. Si le problème vient d’un fichier source et non de la destination, consultez Si le fichier source est introuvable.

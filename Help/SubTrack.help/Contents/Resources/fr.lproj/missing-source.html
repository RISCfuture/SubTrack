Si le fichier source est introuvable

Une file d’attente conserve une référence à chaque fichier, et non une copie, et cette référence subsiste après la fermeture de SubTrack. Une file laissée en place pendant la nuit peut donc retrouver un fichier qui a été déplacé, renommé, supprimé ou qui se trouve sur un disque que personne n’a encore monté. La ligne passe au rouge et indique La source est manquante.

Il existe une variante moins évidente du même problème. L’ajout d’un fichier est ce qui donne à SubTrack l’autorisation d’y accéder, et cette autorisation est enregistrée pour continuer de fonctionner après un nouveau lancement. Les autorisations enregistrées peuvent devenir obsolètes : le fichier est exactement là où vous l’avez laissé, mais la ligne indique que la référence enregistrée n’est plus valide, ou que SubTrack n’a pas l’autorisation de l’ouvrir.

Restaurer le fichier

  1. Remettez le fichier en place – montez le disque, annulez le changement de nom, récupérez-le dans la corbeille.
  2. Sélectionnez la ligne, puis choisissez File d’attente ▸ Réanalyser la sélection.
  3. Si la ligne est toujours signalée, choisissez File d’attente ▸ Retirer la sélection (Delete), puis ajoutez de nouveau le fichier.

La troisième étape est celle qui supprime une autorisation obsolète, et c’est pourquoi elle est toujours recommandée : l’ajout d’un fichier est ce qui donne l’accès, donc l’ajouter de nouveau redonne l’accès. Retirer une ligne ne supprime jamais rien du disque.

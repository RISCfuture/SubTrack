Choisir entre les deux versions de SubTrack

SubTrack existe en deux versions : l’une sur le Mac App Store, l’autre à télécharger sur le web. Elles allègent les fichiers de façon identique – mêmes règles, mêmes préréglages, même copie des flux, même résultat, octet pour octet. Pour ce qui fait la raison d’être de l’app, il n’y a aucune différence entre elles.

Trois fonctionnalités les distinguent, et toutes les trois tiennent aux règles de l’App Store, non à un choix de SubTrack. Si vous êtes arrivé ici en cliquant sur un « ? » à côté d’un réglage grisé, ce réglage est l’une de ces trois fonctionnalités.

Savoir quelle version vous utilisez

  1. Choisissez SubTrack ▸ Réglages (⌘,) et cliquez sur Encodage.
  2. Lisez la ligne Jeu de codecs. Complet (tous les codecs) correspond à la version téléchargeable ; App Store (VideoToolbox) correspond à la version App Store.

La version App Store n’a pas non plus d’onglet Mises à jour dans les Réglages, car c’est l’App Store qui s’occupe de ses mises à jour.

Ce que la version App Store ne peut pas faire

L’encodage H.264 et H.265 logiciel. La version App Store intègre un FFmpeg sous licence LGPL, sans libx264 ni libx265 – ces deux bibliothèques sont sous GPL, et les conditions de l’App Store sont incompatibles avec la GPL. L’encodage vidéo est confié à VideoToolbox, l’encodeur matériel de votre Mac, qui prend en charge H.264 comme HEVC et qui est bien plus rapide que l’encodage logiciel. Les encodeurs logiciels offrent plus de qualité pour une même taille de fichier ; les encodeurs matériels terminent plus tôt. Vous le constaterez dans Réglages ▸ FFmpeg ▸ Formats pris en charge, où la liste des codecs comporte un lien Codecs manquants ?, ainsi que dans l’avertissement qui s’affiche si vous choisissez un codec cible que cette version ne peut pas encoder.

Utiliser votre propre FFmpeg. Dans Réglages ▸ FFmpeg, la version App Store affiche Intégré et la ligne « L’utilisation d’un ffmpeg personnalisé est disponible dans la version téléchargeable. ». La version téléchargeable propose à la place un choix Intégré / Personnalisé…, accompagné d’un bouton Détecter automatiquement qui trouve les versions de FFmpeg déjà installées sur votre Mac. Une app confinée dans un bac à sable ne peut pas exécuter un programme que vous lui fournissez, et la version App Store est confinée ; la version téléchargeable ne l’est pas, ce qui lui permet de le faire.

Installer l’outil en ligne de commande subtrack. Dans Réglages ▸ CLI, la version App Store affiche « L’installation de l’outil en ligne de commande est disponible dans la version téléchargeable. » là où la version téléchargeable propose Installer…. Copier un exécutable dans un dossier de votre PATH sort du cadre du bac à sable.

En plus de ces trois fonctionnalités, la version téléchargeable consulte GitHub pour trouver ses propres nouvelles versions et peut vous prévenir qu’une version est disponible. La version App Store n’en a pas besoin.

Aucune des deux versions n’est bridée. L’allègement – retirer des pistes et copier les autres – n’est en rien affecté, et le transcodage fonctionne dans les deux ; seul l’encodeur utilisé diffère.

Obtenir l’autre version

La version téléchargeable est notariée par Apple et s’installe depuis une image disque ; vous la mettez à jour vous-même quand elle vous signale qu’une nouvelle version est disponible. La version App Store s’installe et se met à jour comme tout le reste sur votre Mac.

  • Le site web de SubTrack, qui renvoie vers les deux versions.
  • Les versions de SubTrack sur GitHub, pour la version téléchargeable et ses notes.

Vous pouvez installer les deux. Elles partagent le même conteneur iCloud : vos préréglages se synchronisent donc entre elles, tout comme entre vos Mac.
